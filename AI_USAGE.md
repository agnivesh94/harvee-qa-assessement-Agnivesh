# AI Usage Disclosure

## Purpose

AI assistance was used during the preparation of this QA Automation assessment to support test design, automation implementation, debugging, and documentation.

## Tools Used

- ChatGPT
- Python, Playwright, and pytest for implementation and execution of the automated tests
- Visual Studio Code for editing and running the project

## Areas Where AI Assisted

### 1. Test Design and Review
- Reviewed test scenarios for login, product sorting, cart operations, checkout, validation, and access control.
- Helped identify weaknesses in assertions, locators, test data, and failure diagnosis.
- Suggested additional positive, negative, and validation scenarios.

### 2. Automation Framework
- Assisted with structuring the project using the Page Object Model.
- Helped develop and review Python Playwright page objects and pytest tests.
- Suggested environment-based configuration and reusable fixtures.
- Helped configure HTML reporting and failure-screenshot capture.

### 3. Debugging and Validation
- Helped investigate a pytest fixture warning.
- Suggested installing `pytest-base-url` to address the warning.
- Assisted with reviewing test execution output and identifying next steps.

### 4. Documentation
- Assisted with drafting the README, assessment answers, defect report, AI-feature evaluation criteria, and client communication.
- Helped organize the documentation into the required assessment sections.

## Human Review and Verification

The automation was executed locally against the public Sauce Demo practice application. The latest recorded full-suite run completed with 10 passed tests and no failures.

AI-generated suggestions were reviewed and adapted to the existing project structure. The candidate remains responsible for understanding the implementation, verifying the code, and ensuring that all submitted statements accurately represent the work performed.

The rewritten code documented in Section B1 should not be considered independently verified unless that exact version has been executed successfully.

## Limitations

AI suggestions may contain incorrect assumptions, incompatible code, incomplete test coverage, or inaccurate claims. Test results and application behavior must therefore be checked directly. AI-generated content is treated as assistance rather than a substitute for QA judgment.

No confidential client data or credentials should be included in prompts or committed to the repository.
